# My Collectives 🎬

A TikTok-style vertical video reel that shuffles and plays your **local video library** — no internet, no algorithms, just your own footage.

Built with React Native + Expo. See the full source code in this repo.

## Quick Start
```bash
git clone https://github.com/techris101/My-Collectives.git
cd My-Collectives
npm install
npx expo start
```
